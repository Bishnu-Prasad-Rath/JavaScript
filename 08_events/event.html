What are Events in JavaScript?

Events are actions or occurrences that happen in the browser, which you can respond to using JavaScript. They allow for interactive web pages.

Event Object Properties

When an event occurs, the browser creates an event object with properties describing the event.

Target Elements

target: The element that triggered the event

currentTarget: The element that the event handler is attached to

srcElement: Alias for target (older browsers)

toElement: Used in mouseover/mouseout events

Keyboard Properties

altKey, ctrlKey, shiftKey: Boolean for modifier keys

keyCode, which: Code of pressed key (deprecated)

charCode: Unicode value of character (deprecated)

Modern code should use key property instead

Mouse Coordinates

clientX/clientY: Relative to viewport

pageX/pageY: Relative to document

screenX/screenY: Relative to screen

offsetX/offsetY: Relative to target element

Event Types

Mouse Events

click: Element is clicked

dblclick: Element is double-clicked

mouseover: Mouse moves onto an element

mouseout: Mouse moves out of an element

mousemove: Mouse moves over an element

mousedown: Mouse button is pressed

mouseup: Mouse button is released

Keyboard Events

keydown: Key is pressed down

keyup: Key is released

keypress: Key is pressed (deprecated)

Form & Window Events

focus/blur: Element gains/loses focus

submit: Form is submitted

change: Input value changes

input: Input value is being changed

load/unload: Page loads/unloads

resize: Window is resized

scroll: Element is scrolled

Event Methods

// Preventing default browser behavior
event.preventDefault();

// Stopping event propagation
event.stopPropagation();

// Stopping immediate propagation
event.stopImmediatePropagation();
