How the JavaScript Event Loop Works

JavaScript is single-threaded, meaning it can only execute one operation at a time. However, it can handle asynchronous operations through the event loop mechanism.

The Components:

  • Call Stack: Where function calls are stored and executed (LIFO - Last In, First Out)
  • Web APIs: Provided by the browser (setTimeout, DOM events, HTTP requests)
  • Callback Queue: Holds callback functions waiting to be executed
  • Event Loop: Continuously checks if the call stack is empty and moves callbacks from the queue to the stack
// Example of asynchronous JavaScript console.log('Start'); setTimeout(function() { console.log('Timeout callback'); }, 2000); console.log('End'); // Output: // Start // End // Timeout callback (after 2 seconds)

Process Explanation:

  1. "Start" is logged to console
  2. setTimeout is called and handed off to Web APIs
  3. "End" is logged to console
  4. After 2 seconds, the timeout callback moves to the Callback Queue
  5. When the Call Stack is empty, the Event Loop moves the callback to the Stack
  6. "Timeout callback" is logged to console
